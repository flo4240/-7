## 2. commit 정책
readme파일의 commit은 각자가 필요한 것이 생겼을 시 먼저 생각한 사람이 commit하기로 하였고, commit기간은 따로 정해두지 않은채 commit 횟수만 최대한 비슷하게 진행하였습니다. 그리고 각자 .md파일을 하나씩 맡았기 때문에 사진 첨부는 각자의 .md파일에만 commit 하기로 하였고 read.me 파일에는 사진 첨부 하지 않기로 결정했습니다.

---
## 3. commit 규칙
main의 read me 파일의 경우 한명이 대표적으로 작업한 후 세세한 내용은 서로 보완하며 완성시키기로 하였으며, 
주제중 맡은 부분들에 대해서는 각자의 branch안에서 md 파일을 하나씩 맡아 커밋수만 맞추어 내용을 완성시키기로 하였습니다.
